# Workflow OpenClaw

Ce document décrit le déroulement du travail entre OpenClaw, Claude Code et Mickaël.

## Étapes

1. **Lecture de la mémoire** — OpenClaw lit `PROJECT_MEMORY.md` pour comprendre le contexte du projet.
2. **Analyse** — OpenClaw analyse le projet (structure, code, objectifs).
3. **Découpage** — OpenClaw découpe le travail en tâches claires.
4. **Exécution** — Claude Code exécute les tâches techniques.
5. **Vérification** — OpenClaw vérifie les changements avec `git diff` et `git status`.
6. **Validation** — Mickaël valide les modifications.

## Règle stricte

**Aucun commit n'est créé sans validation humaine.**
